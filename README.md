Markdown# 🎫 TicketDesk: Cloud-Native AWS Helpdesk (POC)

TicketDesk is a modern, cloud-native IT support ticket tracking application deployed on AWS. The project features a containerized FastAPI backend, a static single-page frontend served globally via CloudFront, an automated serverless thumbnail generator via AWS Lambda, and an isolated PostgreSQL database on RDS. 

The entire infrastructure is 100% defined using **Terraform (Infrastructure as Code)**, and application deployments are fully automated using **GitHub Actions with OIDC authentication**.

### How Request Flows Work:
1. **Frontend Delivery:** Users access the global CloudFront distribution URL. CloudFront fetches static web assets (`index.html`) directly from a private S3 bucket secured via **Origin Access Control (OAC)**.
2. **Backend Routing:** Requests targeting `/api/*` are routed by CloudFront to an **Application Load Balancer (ALB)** located in public subnets. The ALB forwards traffic to private **ECS Fargate** tasks running the FastAPI backend.
3. **Database Security:** The ECS application tasks communicate with an **RDS PostgreSQL** database located in isolated private subnets. Database credentials are generated securely and read at runtime from **AWS Secrets Manager**.
4. **File Attachments & Serverless Processing:**
   * When attaching files to a ticket, the browser requests a time-limited **S3 Presigned URL** from the backend (`/api/tickets/{id}/presigned-url`).
   * The browser uploads the file **directly to the S3 Uploads Bucket**, bypassing the API server to save CPU/bandwidth.
   * Uploading an image triggers an **AWS Lambda function** (`s3:ObjectCreated:*`), which downloads the image, resizes it to a 200x200 thumbnail using `Pillow`, and writes it back to a `thumbnails/` folder inside the bucket.
